# Collaboration Entry

This directory is the source-neutral collaboration entry for work in this
repository. A human or AI worker must receive the same task package regardless
of IDE or model.

For the reading-summary feature, read in this order before planning or editing:

1. `docs/collaboration/reading-summary/s1-feature-spec.md`
2. `docs/collaboration/reading-summary/s2-module-package-draft.md`
3. The assigned module handoff when it exists.

Only the current package and its evidence files are feature authority. Chat
history, a worker's assumptions, and copied template text are not repository
facts. Unknown facts must remain `unknown` until verified from this repository
or its configured remote.
