## Contract and Format Assumptions

- `renderSummary(entries)` accepts an array of normalized `ReadingEntry` values with unique, non-blank string `id` and `title`, `status` in `unread|reading|completed`, and `priority` in `normal|high`.
- Legacy statuses are rejected; this renderer does not interpret or map them.
- Output is four sections/lines: `unread: N`, `reading: N`, `completed: N`, and `high priority:` followed by zero or more `- <id>: <title>` lines.
- High-priority entries are sorted by JavaScript default string relational ordering, i.e. UTF-16 code-unit order of `id`.
- Empty input returns the four-line count/header output with no item lines.
- Rendering is pure: the input array and entries are not modified; equal input produces byte-for-byte equal output.
